# Bootstrap transport

The complete Spatial Engineering Platform v0.5 source tree is stored in `spatial-engineering-platform.tar.gz.b64`.

Run from the repository root:

```powershell
.\spatial-engineering-platform\bootstrap\install-spatial-platform.ps1
```

After extraction and verification, commit the materialized source tree and remove the encoded archive. See the parent `README.md` and `INTEGRATION_PLAN.md` for the required sequence and architectural boundaries.
