Implementation rationale

Keep the existing three-zone Tauri workspace: a dominant renderer, a left accordion for prerequisites, and a mutually exclusive right-side settings/help dock. Package validation is the gate for Analysis; analysis reveals cleanup review; only a kept candidate can be extracted; only an extracted object can be applied and exported. Treat geometry, calibrated camera evidence, segmentation, provenance, and cleanup as contextual outputs around the selected object rather than separate product modes. Low-confidence image adjudication remains an explicit optional action and never silently alters a review decision.
