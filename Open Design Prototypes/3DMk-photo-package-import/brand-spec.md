# 3DMK import refinement — visual binding

**System:** a dark, dense terminal system adapted for a precision 3D workspace: sharp panels, tabular metadata, and a restrained mint action signal.

  --bg: oklch(0.145 0 0);

## Posture rules

1. Dark-only surfaces reduce glare during long inspection sessions.
2. Use sharp 1px separators instead of rounded containers or shadows.
3. Keep metadata tabular, compact, and visible at a glance.
4. Reserve mint for readiness and the single primary action.
5. Use 150ms state transitions; do not animate data decoratively.
