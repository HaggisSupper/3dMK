# Open Design Prototypes

The HTML files in this directory are historical visual and interaction experiments. They are retained only as design references.

They are **not**:

- current product source;
- an implementation plan;
- a persistence or API contract;
- proof that a feature exists;
- a supported launcher;
- a source of current brand, layout, or workflow requirements.

The current UI source is `../public/index.html` and, as Task 15 proceeds, the focused modules extracted beneath `../public/`.

Current product and UX requirements are defined by:

- `../docs/CURRENT_STATE.md`
- `../docs/superpowers/specs/2026-08-07-3dmk-world-class-quality-standard.md`
- `../docs/superpowers/plans/2026-07-31-vwm-authoritative-revision-workflow.md`

Prototype-specific handoff documents, manifests, and duplicated brand notes have been deleted from the active tree. Git history preserves them. Any concept reused from a prototype must be re-expressed in a current governing document and implemented through the authoritative Rust project/revision architecture.
