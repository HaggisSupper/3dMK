# 3DMK exchange and subsurface repair

Date: 9 October 2026. Base repository commit: `7a2e801b4cb451c80255bfb8bd382c2e1e4a5314`.

## Delivered source changes

- Preserve original GLB bytes as the source of truth. Unchanged GLB export returns those bytes. Import traverses scene hierarchy and instances, applies original JSON transforms in double precision before local rebasing, transforms normals correctly and retains raw JSON, material references, extras, and per-primitive attributes. Original source files preserve embedded textures/materials/hierarchy across project save/reopen.
- Keep project/revision/asset identities across ZIP save/reopen. Verify payload digests, graph references, ancestry and record conflicts. Reopening an active child selects its render asset. Staging prevents partial commits. Existing conflicting project state is preserved.
- Crop indexed/nonindexed meshes by complete triangles with UVs, colors, normals, material groups and source IDs retained. Partial triangles are excluded, not geometrically clipped. Unsupported interleaved/morph buffers fail explicitly. Large crop no longer spreads an unbounded array into a function call.
- Maintain original Tauri/Axum/Three.js viewer, source PBR materials, and engineering-object metadata inspector. General, Indoor, Geospatial and Subsurface profiles make room recognition optional.
- Consume GLBAdapter's `mavis.glb-exchange/1` metadata without adding another converter. Canonical WellForge and other exchange payloads stay separate from editable display geometry. The old oilwell conversion path fails explicitly rather than synthesizing fictitious sections or formation geometry.
- Track legacy processing requests with server jobs. Cancellation discards late results and cannot transition to Complete. Undispatched queued admissions expire after 120 seconds when the next request is admitted.
- Add indexed SEG-Y slice viewing with random-access trace reads, inline/crossline/sample selection, LOD, 512×512 maximum returned samples, eight cached slices and two concurrent readers. Input limit is 512 MiB and 250,000 traces. No full-volume GPU allocation is required.
- Integrate the new 3DMK icon source and Tauri icon configuration.

## Important boundaries

- Browser geometry edits are previews. Save Project refuses divergent previews instead of silently replacing authoritative geometry with a flattened PLY. Export Derived Model remains available, but is not an unchanged semantic exchange roundtrip.
- Legacy native processing workers are not preempted. Cancellation suppresses their result; they may finish background computation and leave non-authoritative temporary output. This is disclosed in the UI.
- Camera-set project restoration is explicitly rejected until its record contract is implemented. The bounded restore gate is not a claim that every historical project schema is supported.
- SEG-Y support is big-endian rev 0/1 with IBM32, IEEE32, signed int32/int16/int8 samples. Rev 2+, variable sample counts/timing, prestack duplicate bins, unknown extended-header counts, SEG-D and VOXL are explicitly unsupported. A separate dataset index/cache is not embedded in the project package.
- A seismic overlay requires an already depth-sampled dataset and explicit metre/CRS/datum registration. Time samples are never treated as depth or converted without a velocity model. Model/frame changes invalidate registration.
- GLBAdapter line geometry uses a disclosed schematic radius, not physical borehole diameter. LAS logs without georeferencing remain nonspatial. CRS/vertical datum ambiguity must be resolved before combining datasets.
- No Windows runtime testing or promoted replacement EXE is implied by source/tests. The existing Drive release remains intact. Linux browser testing encountered disabled WebGL; the UI now reports this clearly. Native Linux compilation requires GTK3/WebKit development packages, unavailable through the current permitted VM installation route.

## Verification and reproducible commands

Root tests use the repository's pinned Veritas contract crate at commit `01bbb771dfcbc5c7cb18711bffd8793e693688fd`. In this VM, Cargo Git authentication was unavailable, so an exact connector-retrieved source copy was substituted via Cargo's explicit patch option; the dependency source itself was unchanged. An offline metadata test accepts the same override through `CARGO_METADATA_CONFIG` and an optional host filter through `CARGO_METADATA_FILTER_PLATFORM`.

```
export CARGO_METADATA_CONFIG='patch."https://github.com/HaggisSupper/Veritas.git".federated-rag-contract-governance.path="/absolute/path/to/Veritas/crates/contract-governance"'
export CARGO_METADATA_FILTER_PLATFORM=x86_64-unknown-linux-gnu
cargo test --all-targets --config "$CARGO_METADATA_CONFIG"
cargo test -p vwm-io --manifest-path VWM-Repo-Implicit/Cargo.toml
node tests/geometry_integrity.mjs
```

The JS test uses Three.js 0.160.0 from the official npm registry. The small SEG-Y fixture is from the official Equinor/segyio repository, with commit, SHA-256 and licensing/provenance documented beside it. It is a synthetic deterministic test fixture, not field data.
